隐私政策

适用于 Yetera iOS 应用（1.0）。生效日期：2026 年 10 月 11 日

Yetera 是由 Shunyu Yao 以 Caelune 品牌提供的 iOS 应用。个人信息处理者：Shunyu Yao。 隐私联系邮箱：caelune.support@gmail.com。

本政策说明 Yetera 应用、官网访问和主动邮件联系分别涉及的信息，以及你可以如何管理这些信息。

Yetera 应用处理的信息

根据你的使用方式，Yetera 会在设备本机保存：

  • 你添加的物品：名称、价格与币种、分类、日期、状态、备注，以及你选择的「为什么想要」。
  • 你设置的目标及相关金额。
  • 部分个人资料和应用偏好：昵称、收入或时薪、默认币种、语言、外观、头像选择。
  • 你为已经买下的物品主动添加的照片，以及你主动选择的自定义头像图片。
  • 本机提醒标识。Yetera 会安排系统本地通知；通知内容可能显示你输入的物品名称。

Yetera 保存的照片文件（包括物品照片和自定义头像）留在设备上，不包含在 Yetera 的 JSON 备份中，也不会通过 Yetera 当前的 iCloud 同步功能上传。这仅说明 Yetera 自身的同步与导出范围；应用没有将这些照片排除在 iOS/iCloud 设备备份之外，是否进入设备备份取决于 Apple 的系统备份行为和你的设备设置。

本机存储、iCloud 与 Apple 服务

核心记录保存在应用的本机数据库中。使用 Yetera 不需要注册账号或登录。

在支持 iCloud 的 iOS 版本中，只要设备上的 iCloud 可用，Yetera 就会自动使用你在 iOS 系统设置中登录的 Apple 账户，将选定的决定、目标和部分资料字段同步到关联的 Yetera CloudKit 私有数据库；应用内没有单独的同步启用开关。你可以在 iOS 系统设置中管理 Yetera 的 iCloud 访问。iCloud 或网络暂不可用时，应用仍可在本机使用，服务恢复后同步会继续；使用「清空所有数据」后，本机同步会暂停，直到你明确重新连接。照片不会通过 Yetera 当前同步功能上传；这不代表照片被排除在 iOS/iCloud 设备备份之外，设备备份依 Apple 系统行为及你的设置处理。用于协调免费额度的一小组按环境区分的标识哈希可能通过 Apple iCloud 键值存储，在你自己的 Apple 账户内同步；这些标识不含你写下的文字。

Yetera 使用 Apple StoreKit 读取商品信息并完成一次性 Lifetime 商品的购买或恢复。付款由 Apple 处理，Yetera 不会取得你的支付卡信息。应用会在设备 Keychain 保存有限的权益状态和免费使用状态。

系统文件与分享界面可用于导出或导入 JSON 备份。备份包含决定、目标及部分资料字段，不包含照片或购买状态。导出后，副本由你选择的保存或分享服务管理，Yetera 无法控制其后续保留或删除。

Apple 的 CloudKit、iCloud 键值存储、StoreKit 和系统本地通知是 Apple 提供的系统服务，Apple 会按照其隐私说明处理相关服务信息：Apple 隐私政策。

分析、诊断与第三方

Yetera 不含广告，也不集成第三方分析、广告或崩溃上报 SDK。Yetera 不会将你的应用记录发送到 Yetera 自营的服务器或接口。

Apple 为 App Store Connect 提供的使用分析，可能包括会话、崩溃等指标；Apple 文档说明，这类 App Store 使用数据仅来自同意向开发者分享诊断与使用信息的用户。TestFlight 是独立的测试分发服务：TestFlight 测试者会自动向开发者分享崩溃日志，开发者可在 App Store Connect 查看测试版会话与崩溃指标。如果你主动提交 TestFlight 截图或文字反馈，Apple 会把你提交的反馈及反馈页面显示的相关测试者、应用版本和设备信息提供给开发者。这些说明分别适用于 App Store 分析、TestFlight 测试指标与测试者主动反馈，不代表 Yetera 集成了自己的分析或崩溃 SDK。

官网访问与邮件联系

本网站由 GitHub Pages 托管。网站源码不包含 Yetera 的广告或分析脚本，也不加载远程字体或 CDN 资源。GitHub 说明，访问 GitHub Pages 网站时，GitHub 会为安全目的记录并存储访客 IP 地址。这属于网站托管层的访问记录，与 Yetera 应用中的购买决定、目标、资料或照片分开处理。详情见 GitHub Pages 说明 和 GitHub 隐私声明。

如果你主动写信到 caelune.support@gmail.com，我们会收到你的发件邮箱地址、邮件内容、附件，以及你选择在邮件中提供的信息，并仅用于回复、排查和处理支持或隐私问题。该邮箱使用 Gmail；邮件在传输和存储过程中由 Google 提供服务处理，详见 Google 隐私权政策。请不要通过邮件发送密码、支付凭据或其他不必要的敏感信息。

网站访问和主动邮件联系的数据不会自动并入 Yetera 应用记录，也不会因此发送到 Yetera 应用服务端。

保存与删除

应用本机记录会保留在设备上，直到你删除它、使用「清空所有数据」或移除应用，具体还受 iOS 自身行为影响。

  • 你可以在应用中逐条删除记录或目标。
  • 「清空所有数据」（个人页 → 数据与备份）会清除这台设备上的物品、记录、目标、金库余额和本机照片，但不会删除已经同步到 iCloud 的记录；本机同步会暂停，之后你可以明确选择重新连接。
  • 删除已同步的单条记录会生成同步删除事件并随同步传播。
  • 导出的备份副本由你和所选保存或分享服务管理。
  • 购买记录由 Apple 管理。「清空所有数据」不会清除本机保存的权益状态。

支持邮件及附件保存在接收该地址邮件的 Gmail 邮箱中。问题处理完毕后，我们最多保留相关邮件及附件 6 个月，之后删除我们控制范围内的副本；适用法律要求继续保存的除外。Google 自身依法或按系统流程保留的副本，依 Google 的政策处理。

你的选择与隐私请求

当 iCloud 可用时，支持版本会自动同步选定数据；你可以在应用个人页查看同步状态，并在 iOS 系统设置中管理 Yetera 的 iCloud 访问。清空本机数据后，如需重新连接须明确确认。你也可以管理到期提醒、创建和删除应用记录，并选择是否导出或导入备份。

如需就支持邮件或其他个人信息提出查询、更正、删除等隐私请求，请联系 caelune.support@gmail.com。我们会按适用规则核实并处理。应用记录也可以按上面的说明在设备上删除；iCloud 中已有的记录不会因清空本机数据而一并删除。

本政策的变更

政策如有更新，我们会修改本页并标明新的生效日期。
